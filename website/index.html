CROSS-ARCHITECTURE ENGINE

Cross-Architecture Matrix

Diagnoses chipset & OS risks across participant laptops prior to the session.

Architecture / OS Recommended Tool Known Risk Mandatory Fallback Action
macOS Intel Mac Ollama CLI (`ollama serve`) LM Studio GPU acceleration missing / freeze risk Provide Ollama CLI fallback guide (`docs/18-intel-mac-prep.md`)
Apple Silicon (M1~M4) LM Studio / Ollama / MLX Full Metal GPU acceleration supported MLX (`mlx-lm`) optional recommendation
Windows x86_64 LM Studio / Ollama PowerShell execution policy / Docker WSL2 required Provide PowerShell bypass script (`check_env.ps1`)
Windows Snapdragon ARM Ollama CLI (Native) Performance degradation under x64 emulation Use Ollama Native build
Linux / ChromeOS Ollama CLI No GUI / Sandbox container Use `ollama serve` terminal mode & small models
