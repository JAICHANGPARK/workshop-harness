# Workshop FAQ Generator Skill

## Purpose
Reduces repetitive Q&A during live sessions by pre-generating a comprehensive FAQ document that attendees can consult before and during the workshop.

## FAQ Categories

### 1. Hardware & Environment
- What are the minimum hardware requirements?
- Can I use an Intel Mac / Windows ARM / ChromeOS device?
- How much disk space do I need for model downloads?

### 2. Software & SDK
- Which Python version is required?
- Do I need Docker installed?
- How do I install Ollama / LM Studio?

### 3. API Keys & Authentication
- Where do I get a Gemini API Key?
- Is the API key free or paid?
- What if my API key stops working during the session?

### 4. Network & Offline
- Can I complete the workshop without internet?
- What if the venue WiFi is slow or unstable?
- How do I pre-download models for offline use?

### 5. Code & Debugging
- What if my code produces different output than the facilitator's?
- How do I reset to the starter code if I get lost?
- Where can I find the completed reference solution?

## Output Artifacts
- `docs/20-faq.md` - Complete FAQ document
