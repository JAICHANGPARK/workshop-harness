# Workshop FAQ Generator Skill

## 📌 목적
워크숍 진행 전/당일에 참석자들이 반복적으로 문의하는 질문(하드웨어 사양, 비콘/네트워크, 로컬 모델 다운로드, API 키 비용, OS 호환성 등)을 주제별로 자동 분류하여, 참석자용 **`FAQ.md`** 문서를 체계적으로 생성합니다.

---

## 🎯 주요 생성 항목 및 분류

1. **사전 준비 및 환경 (Preparation & Setup)**:
   - *"내 노트북 사양(8GB RAM, Intel Mac 등)으로 실습이 가능한가요?"*
   - *"Ollama와 LM Studio 중 무엇을 설치해야 하나요?"*
   - *"인터넷이 연결되지 않는 환경에서도 실습이 가능한가요?"*

2. **비용 및 API 키 (Cost & API Keys)**:
   - *"유료 API 키(Gemini / OpenAI 등)가 필수인가요?"*
   - *"무료 크레딧이나 로컬 오픈소스 모델만으로 가능한가요?"*

3. **당일 실습 코드 & 에러 대처 (Code & Troubleshooting)**:
   - *"실습 중 코딩이 막히면 어디를 봐야 하나요?"* (-> `workshop/02_final` 정답 코드 안내)
   - *"PowerShell 또는 Terminal 접근 에러가 날 땐 어떻게 하나요?"*

4. **행사 후 산출물 & 지속 학습 (Post-Workshop)**:
   - *"워크숍이 끝난 후 완성본 코드를 계속 활용할 수 있나요?"*
   - *"실습 자료 PDF는 어디서 다운로드받나요?"*

---

## 📄 FAQ 문서 자동 생성 스펙

`harness_cli.py gen-faq` 또는 에이전트 요청 시 아래 구조의 `docs/20-faq.md`를 생성합니다.

```markdown
# ❓ [참석자 필독] 워크숍 자주 묻는 질문 (FAQ)

## 📌 1. 사전 준비 및 하드웨어 관련
- **Q: 8GB RAM 노트북으로도 진행이 가능한가요?**
  - A: 네, 가능합니다. 다만 8GB RAM 장비는 `gemma4:e2b` 등 2B~3B 이하 경량 모델을 선택하시고, 컨텍스트 길이를 2048 이하로 설정하세요.
- **Q: Intel Mac 사용자인데 LM Studio가 멈춥니다.**
  - A: Intel Mac에서는 LM Studio 대신 Ollama CLI (`ollama serve`)를 기준으로 진행해 주세요. 상세 안내는 `docs/18-intel-mac-prep.md`를 참고하세요.

## 📌 2. 네트워크 및 오프라인 진행
- **Q: 행사장 와이파이가 안 되면 실습을 못 하나요?**
  - A: 사전 준비 가이드(`gemma4-local-setup-guide.md`)에 따라 행사 전 모델과 패키지를 내려받아 두셨다면, 당일 와이파이 없이 100% 오프라인 동작 가능합니다.

## 📌 3. 실습 코드 & 막혔을 때
- **Q: 실습 중 코드를 놓치거나 에러가 나면 어떻게 하나요?**
  - A: 각 세션 폴더에는 완성본 정답 코드(`workshop/02_final`)가 포함되어 있습니다. 코드가 막히면 완성본 코드를 즉시 복사해 붙여넣으실 수 있습니다.
```
